# PRD-SPEC 元素检查清单

对每个元素执行"触发条件"判定必要性，再按"补全动作"取数。
必要性：**必备**=恒定必须；**条件必备**=命中触发条件才必须；**可选**=复杂需求才需要。
来源标注（精简）：默认不标即为已确认；仅标 `≈推断`（AI 补全需复核）、`⚠️待确认`（未定需补齐）；AICoding 资产回填可标来源 `(ai-kit)` / `(rules)`。

## 使用方法

1. 逐条读取本清单。
2. 对"触发条件"做语义判定（IF…THEN…，按语义执行，不做正则硬匹配）。
3. 命中则该元素纳入产出；未命中的"条件必备/可选"元素跳过。
4. 缺失且需要的元素，执行其"补全动作"。
