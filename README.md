# Prompt Lab · 提示词工程工作台

基于原生 HTML、CSS、JavaScript 的本地提示词编辑工具，无需构建步骤，双击或用静态服务器打开即可使用。

## 功能

- **大编辑区**：等宽字体、可纵向拉伸，适合长提示词编写。
- **模板库**：内置多种常用 AI 提示结构（角色任务、CoT、JSON 输出、少样本、代码审查等），一键插入到光标处。
- **`{{}}` 变量**：点击「扫描」识别文中占位符，填写替换值后「全部替换」写回编辑区。
- **工具栏**：格式化（去行尾空白、收敛多余空行）、清空（确认）、一键复制。
- **本地历史**：「保存快照」写入浏览器 `localStorage`，可恢复或单条删除，支持清空全部。

## 文件结构

```
├── index.html      # 页面结构
├── css/style.css   # 深色主题与响应式布局
├── js/main.js      # 交互与存储逻辑
└── README.md
```

## 使用方式

1. 直接用浏览器打开 `index.html`。
2. 若遇剪贴板权限限制，可使用本地静态服务，例如：`npx serve .` 后访问提示的地址。

## 数据说明

历史记录仅保存在本机当前域下的 `localStorage`（键名：`prompt-lab-history-v1`），不会上传服务器。清除站点数据会一并删除历史。
